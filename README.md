# qThrone

Кроссплатформенный клиент для управления прокси на Qt с ядрами [sing-box](https://github.com/SagerNet/sing-box) и [Xray](https://github.com/XTLS/Xray-core).

Форк [Throne](https://github.com/throneproj/Throne) с поддержкой протоколов qWDTT,CSQTT,olcRTC,OpenFlux, а также DNSTT (в планах на ближайшее время).

## Поддерживаемые протоколы

- qWDTT
- CSQTT
- olcRTC
- OpenFlux
- SOCKS
- HTTP(S)
- Shadowsocks
- Trojan
- VMess
- VLESS
- TUIC
- Hysteria
- Hysteria2
- AnyTLS
- Mieru
- Snell
- NaïveProxy
- Juicity
- TrustTunnel
- ShadowTLS
- WireGuard
- AmneziaWG
- MASQUE
- SSH
- Xray VLESS
- OpenVPN/OpenConnect
- Пользовательские исходящие подключения (sing-box и Xray)
- Пользовательские конфигурации (sing-box и Xray)
- Цепочки подключений
- Дополнительные ядра


## Ошибки, предложения и обратная связь

- **Ошибка** — [форма Bug report](https://github.com/saymer-alt/qThrone/issues/new?template=bug_report.yml)
- **Предложение** — [форма Feature request](https://github.com/saymer-alt/qThrone/issues/new?template=feature_request.yml)
- **Свободный вопрос** — [обычный Issue без шаблона](https://github.com/saymer-alt/qThrone/issues/new)
- **Уязвимость** — только приватно через [Report a vulnerability](https://github.com/saymer-alt/qThrone/security/advisories/new); не публикуйте технические детали в Issues.

Перед публикацией обезличивайте материалы: без паролей, токенов, закрытых ключей, подписок, VPN-ключей и приватных IP-конфигураций.
